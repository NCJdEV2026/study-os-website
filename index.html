04 // FAQ
What is STUDY//OS?

A Windows desktop productivity application for students that combines focus sessions, task and subject management, exam tracking, active recall, analytics and progress systems.

Is it a subscription?

No. The current plan is $10 USD as a one-time purchase.

How many devices can I use?

A license can be activated on up to two personal devices.

Does it require internet?

Internet is required for initial license activation and certain license operations. After activation, core study functionality can launch and work offline.

Which platform is supported?

STUDY//OS is currently built for Windows desktop.
